## Overview

**VorteX Axis** is a device gateway for AI agents: one agent, reachable from every device around you, in one continuous conversation. It gives an agent ears, a voice, screens and hands, in the form of clients: small ESP32 clients with a microphone and an animated face, a web client on your phone, and a Windows client on your computer. Say something to whichever device is nearest; the same agent answers, and it can speak, ask a question, or show a picture on any of them.

Axis is a **bridge, not an agent**. It does not think; it listens, routes and speaks. The brain stays behind it, either an OpenClaw gateway or any OpenAI-style chat endpoint.

## What It Does

- **Talk to your agent anywhere.** A wake word, a tap on a client's screen, a press in the web client, a key on your computer. When several devices hear you, one answers.
- **The agent can reach you.** It speaks on one device, one room or everywhere, asks questions with choices you tap or say, sets timers, shows pictures, keeps a long task's progress on every screen, and notifies your phone when you are away.
- **Thin devices.** A device captures and plays audio and draws a face. Speech, settings and the agent link live in Axis, so every device behaves the same and is set up once.
- **Local speech.** Speech recognition, synthesis and speaker voiceprints run on the CPU beside Axis, with no cloud round trip required.
- **Realtime voice option.** A device can switch from the local speech chain to a low-latency realtime voice model, with the agent still doing the real work.
- **Your computer, experimentally.** The Windows client, a tray app, lets the agent read the screen and act on it by control name, with hard limits (no password fields, no system shortcuts) and a per-computer off switch.
- **Home Assistant.** Clients appear as sensors (room sound level, gestures), and tasks and timers can show up as live activities on a phone.

## Architecture

```
 devices                          Axis                          behind it
 -------                          ----                          ---------
 ESP32-S3 clients   ─┐                                       ┌─ the agent (OpenClaw gateway
 web client         ─┼─ one socket ─▶  pairing, settings,  ──┤   or OpenAI-style chat endpoint)
 Windows client     ─┘   per device    turns, wake word,     ├─ speech recognition
                                       tools for the agent   └─ speech synthesis
```

- **Protocol:** one WebSocket per device, JSON for control and binary frames for audio, with a single versioned schema shared by the server and every client.
- **Wake arbitration:** each device detects the wake word locally and reports a score; Axis grants the turn to one device and tells the rest to stand down.
- **Settings:** layered global → device type → device, with Axis as the source of truth, so a reset device re-syncs itself.
- **Agent tools:** the agent gets ten tools (speak, ask, timers, progress, session attach, desktop control and more), through its gateway or over MCP.
- **Server:** a TypeScript service in Docker with SQLite storage; the admin page shows every turn live, stage by stage.

## Clients

- **ESP32 client:** a Waveshare ESP32-S3 with an AMOLED screen, microphone and speaker, running custom firmware with an animated face, offline wake word, tool icons while the agent works, and edge glows for listening, thinking and timers.
- **Web client:** installs on a phone, with notifications, hold-to-talk and questions.
- **Windows client:** a C# / .NET 8 tray app that makes a PC a voice device and, optionally, a screen the agent can see and use.

## The Name

Vortex is the name of the assistant all of this hangs off, a calm agent with a 🌀 for a face. Axis is the line a vortex turns around: the devices orbit it, and it's the bridge between them and the agent.

## The Face Is the Logo

There is no separate logo. The face every screen draws is the mark: three arms of dots winding into a bright core, 3 × 26 = 78 dots. Dots near the core are small and bright; towards the edge they get bigger and softer, so the figure reads as a galaxy or a whirlpool seen from above. Three arms repeat every third of a turn, which is why it looks balanced however it is turned.

## A Colour for Every State

Colour carries the meaning, so idle looks stay in blues and blue-greens on purpose and are never mistaken for anything else:

- **Idle:** blue, one of 14 looks it drifts between every 7 to 17 seconds, never the same twice in a row, so it never looks like a loop.
- **Listening:** green, pulled in tight and swelling with your voice.
- **Thinking:** violet, spinning nearly three times faster than listening, with a little sparkle.
- **Speaking:** white-blue, opening up and pulsing with the voice of the reply.
- **Setup** is amber, **error** is red, **offline** is grey.

## When It Works, the Dots Become the Thing

All 78 dots leave their arms and settle along an icon's outline (a house for the lights, a magnifier for a search, a calendar, a timer) with a wave of light running along the strokes, then swirl back. There are 13 icons. When a run is held up, the face says so: wound tight and deep blue while it tidies its memory, amber and turning backwards while it retries. Each device draws it from a spec: a look is 13 numbers, and the face always eases from its current look to a target one, so a state change never jumps. 20 looks (14 idle, 6 state).
